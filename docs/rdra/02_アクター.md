# アクター

## アクター

| アクター | 説明 | 出典 | 質問 |
|---|---|---|---|
| 顧客 | Web で商品を購入する人。会員登録しなくても購入できる | 要望 | |
| 営業 | 取り扱い商品の登録・削除、売上の分析、品揃えの検討、新規商品の発注を行う | 要望 | |
| オーダー部門 | オーダー処理を集約して行う(新設)。入金の確認、出荷指示、追加発注、返品の受付を行う | 要望 | |
| 物流 | 出荷作業と入荷情報の入力を行う | 要望 | |
| 経営者 | 売上の状況を見る | 要望 | |
